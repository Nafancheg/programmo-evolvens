# Метрики / Metrics

| Metric | RU definition | EN definition |
| --- | --- | --- |
| Task success rate | Доля корректно завершённых заданий | Correctly completed tasks / all tasks |
| p95 latency | 95-й перцентиль задержки | 95th percentile end-to-end latency |
| Recovery time | Время возврата к заданному уровню качества после отказа | Time to regain agreed service level after fault |
| Resource efficiency | Успешные задачи на единицу ресурса | Successful tasks per resource unit |
| Learning gain | Разница качества после/до обучения на отложенных задачах | Held-out performance after minus before learning |
| Capability coverage | Доля классов задач, удовлетворяющих критериям | Fraction of task classes meeting acceptance criteria |
| Regression count | Число ухудшений относительно контрольного поколения | Regressions versus parent/baseline |
| Genesis competence | Точность решения проверочных кейсов с оценкой критических ошибок | Accuracy on assessment cases with critical-error reporting |

**RU:** Для каждой метрики заранее фиксируются единицы, знаменатель, окно наблюдения, пороги и источник данных. Номера G и M не являются самостоятельными доказательствами улучшения.

**EN:** Predefine units, denominators, windows, thresholds and provenance. G and M labels are not independent evidence of improvement.
