# Гипотезы / Hypotheses

## H1 — Обучение / Learning
**RU:** Адаптивная политика улучшает качество на отложенных задачах по сравнению с замороженной политикой при одинаковых ресурсах.
**EN:** Adaptive policy improves held-out task quality versus frozen policy under equal resources.

## H2 — Устойчивость / Resilience
**RU:** Клеточные механизмы изоляции и восстановления уменьшают длительность отказов по сравнению с обычной схемой рестарта.
**EN:** Cell isolation and recovery reduce disruption duration compared with conventional restart handling.

## H3 — Эволюция / Evolution
**RU:** Допущенное Genesis новое поколение устраняет воспроизводимый функциональный разрыв без деградации обязательных инвариантов.
**EN:** A Genesis-approved generation closes a reproducible capability gap without violating mandatory invariants.

## H4 — Коэволюция / Co-evolution
**RU:** Обновлённый Genesis лучше обнаруживает ошибочные эволюционные предложения на закрытом наборе случаев без роста опасных пропусков.
**EN:** Updated Genesis detects faulty evolution proposals better on blinded cases without increasing dangerous misses.

Каждая гипотеза пока непроверена. / All hypotheses remain untested.
