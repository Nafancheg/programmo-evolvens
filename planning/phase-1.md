**RU:** Текущая цель — развитие организма из генома до проверяемой пищеварительной функции по [модели](../docs/ru/11-bioengine-and-applications.md). **EN:** Current goal: genome-driven organism development toward verifiable digestive function under the [model](../docs/en/11-bioengine-and-applications.md). P1-01…04 record the scalar foundation, not organism readiness. Next path: P0-09 and P1-13/P2-01 → P1-17 → P1-18 → P1-16; intake, persistence and search P1-12/14/15 progress concurrently according to dependencies. External agents and LLMs are not runtime dependencies.

**Граница исполнения / Execution boundary:** по [ADR-006](../adr/006-world-before-organism.md) развивающиеся варианты и автономный подбор запускаются после приёмки мира P2-09 в [W0](world.md).
