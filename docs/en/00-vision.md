# Vision and Scope

[Русская версия](../ru/00-vision.md) · [Project home](../../README.md)

## Purpose
Build an autonomous organism developing mechanisms and organs from its genome. Before execution, engineer and verify [virtual world W0](13-virtual-world.md) with external quotas and permissions; the world does not co-evolve with the organism. Inside an accepted world, feeding and information assimilation are the first target capability, without external AI agents. Application products belong to the next layer. [Complete model](11-bioengine-and-applications.md), [ADR-006](../../adr/006-world-before-organism.md).

Comparison with conventional software checks practical usefulness. Proof of scientific uniqueness is not a prerequisite for building the system.

## Fundamental thesis
An organism performs externally assigned tasks and develops within its existing generation. Structural reproduction occurs only when a validated capability gap cannot be resolved by learning or configuration.

## Boundaries
This project does not claim consciousness, biological life, autonomous code synthesis or inevitable improvement. All such claims require evidence.

## Actors
- Environment: tasks, constraints, evaluation criteria.
- Organism: execution, learning, regulation, history.
- Genesis: independent testing and generation design.
- Verification protocol: immutable-for-a-trial acceptance criteria and rollback policy.

## Priorities
A working autonomous cycle, explicit contracts, reproducible checks, observable failures and costs, persistence and reuse of outcomes. Arbitrary code generation and universal file understanding are not claimed implemented capabilities.
