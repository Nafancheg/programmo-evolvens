# Биологическая архитектура

[English version](../en/01-biological-architecture.md) · [Главная](../../README.md)

Биология используется как архитектурная аналогия, а не доказательство тождества.

| Аналогия | Ответственность в ПО |
| --- | --- |
| Клетка | Изолированный исполнитель с контрактом и состоянием здоровья |
| Орган | Согласованная функциональная подсистема |
| Геном | Версионированное декларативное описание состава и инвариантов |
| Нервная система | Передача событий и команд |
| Иммунная система | Обнаружение аномалий, карантин, восстановление |
| Эндокринная система | Медленные глобальные регуляторные сигналы, а не прямые команды |
| Метаболизм | Бюджеты ресурсов и планирование |
| Гомеостаз | Управление рабочими диапазонами с гистерезисом |
| Память | История событий и подтверждённые обобщённые знания |
| Регенерация | Восстановление или замена неисправного исполнителя |
| Апоптоз | Контролируемое завершение исполнителя |

Для каждой подсистемы необходимы интерфейсы, наблюдаемые входы/выходы и испытания. В первом прототипе не допускаются биологические названия без измеримого инженерного смысла.
