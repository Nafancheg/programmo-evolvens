# Дашборд лаборатории и установка на другой ПК

[English](../en/17-laboratory-dashboard.md) · [Приёмка W0](16-w0-acceptance.md) · [Фаза наблюдения](../../planning/phase-6.md)

## Открыть лабораторию

Из корня репозитория в PowerShell:

```powershell
.\scripts\start-lab.ps1
```

Откроется `http://127.0.0.1:8765`. Терминал поддерживает сервер; Ctrl+C завершает наблюдение. Другой порт: `-Port 8766`; без открытия браузера: `-NoBrowser`. Можно также выполнить `python -m programmo_evolvens.lab --open`.

Страница показывает текущую пробу, CPU, память, число процессов/потоков, применимость приёмки W0, последние 80 запусков и исходные события с хешами. Данные обновляются раз в две секунды. Поиск фильтрует ID и пробы; выбор строки раскрывает исходное событие. Кнопка паузы останавливает обновление страницы, а не мир. Интерфейс переключается RU/EN.

Короткая проба может закончиться между двумя измерениями: тогда её фактический пик памяти виден в журнале, но не обязательно на живом графике. CPU вычисляется по разности внешних счётчиков; первое измерение нового запуска не имеет оценки. При отсутствии источника показывается ошибка, а не выдуманные нули. Прерванный запуск отличается от завершённого; ожидаемые остановки подтверждённой серии приёмки помечены отдельно.

Первое предписанное развитие клеток показано в [ограниченном эксперименте](18-prescribed-development.md); поколения и функции органов ещё впереди. Дашборд не запускает и не изменяет организм. Приёмка считается применимой только при совпадении хешей контроллера, политики, seccomp, манифеста rootfs и испытателя с установленными компонентами.

## Новый Windows-ПК

Поддерживаемая цель первого установщика: Windows x64 с WSL2 Ubuntu/Debian, Python 3.11+ в Windows и доступом к репозиториям пакетов. Node, Docker, npm и внешние ИИ не нужны. Фактически проверено на текущем Ubuntu-26.04/Python 3.14; чистый второй ПК и systemd-дистрибутив пока не проверялись.

Если WSL ещё нет, установите его по [инструкции Microsoft](https://learn.microsoft.com/en-us/windows/wsl/install): `wsl --install -d Ubuntu`, выполните запрошенный перезапуск и первый вход. Windows Python доступен на [официальной странице](https://www.python.org/downloads/windows/). Скрипт проверяет эти предпосылки и объясняет, чего не хватает; сам не перезагружает Windows и не создаёт дистрибутив без отдельной команды пользователя.

Склонируйте репозиторий или распакуйте ZIP. Из его корня:

```powershell
.\scripts\setup-lab.ps1 -InstallDependencies
.\world\wsl2\config\run-acceptance.ps1
.\scripts\start-lab.ps1
```

Если нужен конкретный установленный дистрибутив:

```powershell
.\scripts\setup-lab.ps1 -Distro Ubuntu -InstallDependencies
```

Выбор сохранится в игнорируемом `.local/lab.json`. Последующие команды используют его; параметр `-Distro` или `PE_WSL_DISTRO` позволяет переопределить выбор. Имя Ubuntu-26.04 и путь к пользовательской папке в установщике не зашиты. Конфигурацию `.local` с предыдущего ПК переносить не требуется.

Установщик добавляет пакеты `python3`, `bubblewrap`, `libseccomp2`, создаёт root-owned `/opt/pe-world`, ограниченное хранилище журналов и служебную учётную запись. `.wslconfig`, `/etc/wsl.conf`, Docker и режим init сохраняются. Не меняются квоты чужих cgroup; доверенный контроллер возвращает только свой PID в исходную группу. Отсутствие обязательного механизма блокирует запуск.

Журналы и положительный отчёт этого компьютера не делают новый ПК проверенным. Выполните приёмку заново; при неуспехе дашборд остаётся доступен для диагностики, но допуск организмов не подтверждён.

## Обновление и проверка

```powershell
.\scripts\setup-lab.ps1 -CheckOnly
.\scripts\setup-lab.ps1 -UpdateWorld
```

Проверка не меняет установку. Обновление допускается при остановленном мире, блокируется общим lock, сохраняет прежние компоненты в `/opt/pe-world/versions` и не удаляет журналы. Несовпадающая установка без `-UpdateWorld` не перезаписывается. Если изменились компоненты профиля, повторите приёмку. При 16 активных журналах дальнейшие запуски отклоняются: сохраните прежние файлы в `runs/history` в пределах общего бюджета, не удаляя доказательства.

Сервер слушает только `127.0.0.1`; HTTP-интерфейс предоставляет чтение, без управления заданиями. Экспортёр WSL выполняет фиксированный код чтения журналов и cgroup. Страница не передаёт ему команды или произвольные пути.

**Дополнение 2026-11-01:** в лаборатории доступны итоговый экземпляр, геном и код из выполненного пакета, паспорт JSON и пошаговый просмотр записи. После приёмки выполните `.\scripts\run-development.ps1`, чтобы получить экземпляр на этом ПК. [Описание результата](18-prescribed-development.md).
