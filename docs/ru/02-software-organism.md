# Программный организм

[English version](../en/02-software-organism.md) · [Главная](../../README.md)

## Операционное определение
Исполняемая система, которая (1) принимает задания от внешней среды, (2) выполняет их с ограниченными ресурсами, (3) контролирует собственное состояние, (4) меняет политики без изменения исполняемого кода на основе результатов и (5) формирует аудируемый эволюционный запрос при доказанном архитектурном ограничении.

## Состояние
Идентификатор; поколение G; зрелость M; версия генома; клетки и возможности; бюджеты ресурсов; регуляторные сигналы; эпизодическая память и база знаний; здоровье; происхождение данных.

## Инварианты
- Организм не модифицирует произвольно собственный исполняемый код.
- Организм не санкционирует собственную репродукцию.
- Каждое действие и адаптация журналируются со временем, входными данными и результатом.
- Неудачную адаптацию можно откатить.
- Невыполненная задача — свидетельство дефицита, но не автоматическое основание для репродукции.

## Жизненный цикл
Рождение -> работа -> адаптация/обучение -> оценка -> продолжение работы ИЛИ воспроизводство под управлением Genesis. Предыдущие поколения сохраняются для сравнения и отката.
